 <h1 align="center">Swing Library Management System</h1>
<h2 align="center">Overview</h2>

<p>
    The Library Management System is a desktop-based Java application developed to digitize 
    and streamline the management of library resources and study room reservations. 
    The system provides an integrated environment where librarians or administrators can manage books,
    register members, monitor borrowing activities, and control study room bookings 
    through a centralized graphical interface.
</p>
