 <h1 align="center">Swing Library Management System</h1>
<h2 align="center">Overview</h2>

<p>
    The Library Management System is a desktop-based Java application developed to digitize 
    and streamline the management of library resources and study room reservations. 
    The system provides an integrated environment where librarians or administrators can manage books,
    register members, monitor borrowing activities, and control study room bookings 
    through a centralized graphical interface.
</p>

<h2 align="center">Project Description</h2>
    <h3>Introduction</h3>
    <p>
        The Library Management System is a Java desktop application developed to modernize 
        and automate the management of library 
        resources and study facilities. Traditional manual systems often suffer from delayed 
        record handling, inventory mismatches, reservation conflicts, and poor accessibility 
        of information. This project addresses those challenges through an integrated digital platform.
        The system combines book inventory management, member administration, and study room 
        scheduling into one cohesive software environment.
        Built using Java Swing and Object Serialization, the application provides persistent 
        storage, modular navigation, and a visually consistent graphical user interface.
    </p>
    <h3>System Objectives</h3>
    <p>
        The primary objectives of the system include:
        <ul>
            <li>Digitizing library operations</li>
            <li>Reducing human errors</li>
            <li>Improving record accessibility</li>
            <li>Automating borrowing workflows</li>
            <li>Maintaining accurate inventory quantities</li>
            <li>Organizing member information</li>
            <li>Managing physical study room reservations</li>
            <li>Providing a centralized management platform</li>
        </ul>
    </p>
